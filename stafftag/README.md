# StaffTags for Revenge

Плагин StaffTags для мобильного Discord-клиента с модификацией Revenge.

## Установка

Добавьте этот адрес в **Revenge → Plugins**:

```text
https://floralflarya.github.io/revenge/stafftag/
```

Если GitHub Pages ещё не включён, можно использовать прямой адрес:

```text
https://raw.githubusercontent.com/revenge/floralflarya/stafftag/main/
```

Плагин показывает должности исключительно по реальным разрешениям пользователя. Названия ролей не проверяются.

Поддерживаемые теги: `OWNER`, `ADMIN`, `STAFF`, `MOD`, `VC Mod`, `Chat Mod`.

Теги добавляются в чат, профиль и список участников там, где текущая версия Discord позволяет встроить их. Цвет высшей роли используется по умолчанию и может быть отключён в настройках плагина.

Исходный код находится в папке [`source`](source).
