# PingColor for Revenge

Плагин PingColor для мобильного Discord-клиента с модификацией Revenge.

## Установка

Добавьте этот адрес в **Revenge → Plugins**:

```text
https://floralflarya.github.io/revenge/pingcolor/
```

Если GitHub Pages ещё не включён, можно использовать прямой адрес:

```text
https://raw.githubusercontent.com/revenge/floralflarya/pingcolor/main/
```
